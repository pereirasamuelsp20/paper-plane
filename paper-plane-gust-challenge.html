Java Survival Engine

OPEN VIA JAVA SERVER

Java is now connected to the playable game through a small local HTTP server. When you launch PaperFlightServer, the browser requests the survival score from the Java engine about four times per second. Java calculates the score and returns it to the game; the wind, rendering, controls, collision visuals, and audio remain in the browser. If you open the HTML file directly, the game remains playable with local JavaScript scoring.

PaperFlightEngine.javaCore logic excerpt
// Called by PaperFlightServer for the live game.
public static int scoreForElapsed(double seconds) {
    if (!Double.isFinite(seconds)) return 0;
    double safeSeconds = Math.max(0.0, seconds);
    return (int) Math.floor(
        safeSeconds * SCORE_PER_SECOND
    );
}

// PaperFlightServer returns this score as JSON.
// The browser displays Java's result when connected.

Run the integrated Java game

Start the Java server to host the game and activate Java-based survival scoring. The status badge above should read JAVA ENGINE CONNECTED. The game falls back to local scoring if you open the HTML directly.

Download engine Download server

Requires a JDK. In Terminal, run:
javac PaperFlightEngine.java PaperFlightServer.java
java PaperFlightServer
Then open http://localhost:8787.

Integration architecture: the browser sends elapsed survival time to /api/score; PaperFlightServer.java calls the Java engine and returns the score. Java is genuinely part of the running game via this local API; the browser still handles graphics and real-time input.
